# Website Evaluator - CRO & User Flow Auditor Agent

An automated auditing agent and analysis engine for **Conversion Rate Optimization (CRO)**, **User Flow efficiency**, and **Friction Reduction**.

Built following the exact agent architectural blueprint and reporting standards established by [`ada_compliance_auditor.md`](file:///G:/My%20Drive/AI/Skills/ada_compliance_auditor.md) and [`ai_crawlability_auditor.md`](file:///G:/My%20Drive/AI/Skills/ai_crawlability_auditor.md).

## 🎯 Evaluation Dimensions & Points of Consideration

The agent audits websites across 6 core pillars, with primary focus on the key conversion blockers:

1. **The 5-Second Test & Value Proposition Clarity:**
   - Can a first-time visitor immediately identify what the company does, who it serves, and why they should choose them without scrolling?
   - Checks above-the-fold `<h1>` clarity, target audience definition, differentiation claims, and elimination of vague corporate buzzwords.
2. **Call-to-Action (CTA) Friction & Visual Hierarchy:**
   - Are buttons buried, inconsistently styled, or competing with each other?
   - Checks for a single clear primary action on every key page, Hick's law violations (competing equal-weight buttons), button contrast, and action-oriented value microcopy vs. passive labels like "Submit" or "Click Here".
3. **Form Optimization & Funnel Drop-off:**
   - Are forms too long, missing mobile auto-fill, or failing to provide inline error validation?
   - Checks field counts, HTML5 `autocomplete` attributes (`autocomplete="name"`, `autocomplete="email"`, etc.), semantic mobile keyboard types (`type="tel"`, `type="email"`), persistent `<label>` tags, and inline real-time error feedback.
4. **Trust Elements, Social Proof & Risk Reversal:**
   - Absence of verified reviews, client logos, case studies, guarantees, or security badges near conversion points.
   - Audits third-party rating platform integrations (Trustpilot, G2, Google), client/partner logo bars, quantified case studies with customer credentials, risk reducers ("30-day money-back guarantee", "No credit card required"), and security badges (SSL, SOC 2, HIPAA, PCI).
5. **User Flow Continuity & Funnel Navigation:**
   - Checks for funnel leakage on high-intent pages (e.g. checkout, demo sign-up) caused by full navigation menus, dead ends, or distracting outbound social media links.
6. **Mobile Conversion & Touch Ergonomics:**
   - Audits mobile viewport configuration (`width=device-width`), persistent sticky bottom conversion anchors on long pages, and minimum touch target ergonomics.

## 🚀 Usage

### 1. Running the Automated Python Crawler
You can run the auditor directly from the terminal against any target website:

```bash
# Basic audit (crawls base URL and auto-discovers conversion sub-pages)
python cro_auditor.py https://example.com

# Audit with specific key conversion sub-pages
python cro_auditor.py https://example.com /pricing /contact /demo /signup
```

### 2. Using as an AI Agent Skill
Feed the instructions from [`cro_userflow_auditor.md`](file:///g:/My%20Drive/AI/website-evaluator/cro_userflow_auditor.md) into your AI Agent (Antigravity, Gemini, Claude, etc.):

1. **Prompt for Input:** Supply the base URL and target conversion flow URLs.
2. **Crawl & Analyze:** The agent inspects front-end DOM elements, visual hierarchy, above-the-fold content, CTA styles, forms, and social proof.
3. **Generate Report:** Compiles findings into `cro-userflow-report.txt` matching the standardized format with 0-10 numerical ratings and exact CSS/XPath action items.

Call-to-Action (CTA) Friction & Visual Hierarchy: 5/10

Form Optimization & Funnel Drop-off: 3/10

Trust Elements, Social Proof & Risk Reversal: 4/10
https://www.example.com/pricing | Pricing cards lack risk-reversal microcopy ('No credit card required' / 'Cancel anytime') at CSS: .pricing-grid
https://www.example.com/testimonials | Testimonials lack customer photos, full names, company roles, or verifiable third-party review platform links at XPath: //section[@id="testimonials"]/div

https://www.example.com/demo-booking | Dedicated demo booking page retains full navigation header with 38 external links leaking funnel traffic at XPath: //header[@id="site-header"]

Mobile Conversion & Touch Ergonomics: 6/10
https://www.example.com/ | Mobile hero requires user to reach top right hamburger menu to find any conversion path at CSS: .navbar-toggler

============================================================
OVERALL SUMMARY & RECOMMENDATIONS
Overall CRO & User Flow Score: 4.5/10
Conversion Friction Risk Level: High
Primary Funnel Drop-off Bottlenecks:
1. [Form Optimization & Funnel Drop-off] Lead capture form requires 8 mandatory fields causing severe drop-off friction
2. [The 5-Second Test & Value Proposition Clarity] Hero headline fails the 5-second test; lacks explicit mention of what company does
Top Remediation Priorities:
1. Revise hero headline and subhead to explicitly communicate core offering and target audience without scrolling (Ref: XPath: //section[@id="hero"]//h1)
2. Establish a clear primary CTA and replace generic 'Submit' / 'Click Here' labels with action-oriented benefit copy (Ref: CSS: .hero-actions .btn-group)
3. Streamline contact and sign-up forms to maximum 3-4 essential fields with HTML5 autocomplete attributes enabled (Ref: XPath: //form[@id="lead-form"])

END OF REPORT
